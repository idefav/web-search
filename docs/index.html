01

部署服务端

GitHub Pages 只托管这份静态文档。真实服务通过 GHCR 镜像部署到你的 Linux 服务器。

Linux / Docker Compose

      

      
脚本生成两把独立随机密钥，固定 Camofox 与出口代理镜像，并默认只监听 127.0.0.1。填写域名后会启动 Caddy 自动签发 TLS 证书。
