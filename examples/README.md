# Examples

- [`deepagents`](./deepagents): a custom LangChain Deep Agents research Agent using either MCP or REST tools.
- [`agent-configs`](./agent-configs): manual Codex, Claude Code, OpenCode, and Pi configuration files.

The `camofox-web-search` CLI remains the recommended way to install Agent configuration. The checked-in files are useful for auditing, templates, and managed provisioning.
