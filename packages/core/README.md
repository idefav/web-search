# camofox-web-search-core

Shared Zod contracts, pluggable DuckDuckGo/Brave/Bing/Google parsing, URL safety, Camofox REST orchestration, fetch-readiness recovery, provider cooldowns, and typed errors for [Camofox Web Search](https://github.com/idefav/web-search).

Most users should install `camofox-web-search` or `camofox-web-search-client` instead of importing this package directly.
